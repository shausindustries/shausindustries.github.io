Test program

The datapath is verified with a loop-accumulator routine:

    MOV REG1, 3      ; initialise register 1
    MOV REG2, 3      ; initialise register 2
_add:
    ADD REG1, REG2   ; REG1 = REG1 + REG2
    CMP REG1, REG6   ; compare against the limit
    JE  _halt        ; stop when equal
    JNE _add         ; otherwise loop
_halt:
    HLT
